# Artefact-inventaris CEDA funnel

Overzicht van de documenten en formats die we nu gebruiken in ons werk, geordend naar de stap in de funnel. Doel: zien welke formats er al zijn (startpunt voor de go/no-go per fase) en waar er niets ligt. Een lege plek per fase is ook informatie.

## Hoe vullen

Voeg per artefact een regel toe onderaan de tabel, via een pull request of directe commit. Eén regel per artefact. Onbekend veld? Laat het leeg of zet er een vraagteken. Twijfel over de fase: kies de stap waar het artefact wordt gebruikt of waar het de go markeert.

## Fase (kies 1 t/m 4)

1. Probleem naar use case
2. Use case naar MVP
3. MVP naar production-ready
4. Production-ready naar live

## Vorm

Word doc, Git text (md), PPT, PDF, anders (benoem in toelichting).
